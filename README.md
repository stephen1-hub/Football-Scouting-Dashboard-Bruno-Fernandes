# Football-Scouting-Dashboard-Bruno-Fernandes
# Overview

This project is a football analytics scouting dashboard built with Python and Streamlit. It analyzes the attacking profile of Bruno Fernandes using xG/xA metrics, shot profiling, and role-based performance analysis.

The dashboard is designed to simulate a professional club scouting interface (Opta/Wyscout-style), with a focus on decision-making, creativity, and tactical role interpretation.

# Key Features

📈 Player performance overview (Goals, xG, xA, xG/90, xA/90)
🧠 Role-based analysis (MC vs AMC performance impact)
🎯 Shot zone distribution (Penalty area, Six-yard box, Outside box)
🦶 Shot type breakdown (Right foot, Left foot, Head)
⚽ Situation analysis (Open play, Set pieces, Penalties)
📊 Efficiency metrics (xG per shot, shot selection quality)
🧩 Creativity engine (Key passes, assists, xA contribution)
🧠 Scouting insight panel (data-driven interpretation)
🎮 Dark-themed player dashboard UI (Opta-style layout)

# Key Insights
High proportion of shots from low-probability areas (outside the box)
Low shot efficiency from distance (0.04 xG/shot)
Strong attacking output driven by elite chance creation (xA)
Role-dependent performance:
MC → higher goal threat (xG focus)
AMC → elite playmaking (xA focus)
Right foot dominates shooting, while left foot contributes heavily to creativity
Limited presence in high-value scoring zones (six-yard box)
# Scouting Summary

Bruno Fernandes is a high-risk, high-reward attacking midfielder whose output is strongly influenced by tactical role.

He exhibits a tendency toward low-probability shooting, particularly from outside the box, resulting in reduced scoring efficiency. However, this is offset by elite chance creation, especially when deployed in advanced midfield roles.

His overall value lies in creative influence, tactical freedom, and multi-phase attacking involvement rather than pure finishing efficiency.
